========================================
  Codex Desktop 一键汉化包（zh-CN）
========================================

一、这是什么？
  把微软商店版 Codex Desktop 的界面完整变成中文：
  - 左侧会话、新聊天、项目、计划、插件、设置等网页主体文字
  - 顶部 文件/编辑/视图/帮助 原生菜单
  全程离线完成，不需要登录 OpenAI 账号，API Key 模式同样生效。

二、两种使用方式
  方式 A（推荐，一句话）：在 Codex 里打开本仓库目录，对它说：
    「按本仓库 README 和 AGENTS.md 的说明，帮我把 Codex Desktop 界面汉化成中文」
  Codex 会自动运行安装脚本完成汉化（过程中弹出 UAC 请点「是」）。

  方式 B（兜底，双击）：直接双击「安装汉化.bat」，UAC 弹窗点「是」，
  在菜单中选择 1 安装汉化，完成后自动启动汉化版。

三、为什么会有这个包？
  官方 Codex 内置了完整的中文翻译，但默认关闭，由服务器控制。
  本工具在本地强制打开这个"中文开关"，并让程序从汉化副本启动。
  它不会修改原版安装，随时可以一键恢复英文。

四、常见问题
  Q1：打开后还是英文？
  A：先彻底关闭 Codex（任务栏右键退出），再双击「启动汉化版.bat」。
     如果仍然英文，重新双击「安装汉化.bat」选择 1 重新安装一次。

  Q2：Codex 自动更新了新版，汉化失效？
  A：重新双击「安装汉化.bat」选择 1 即可（会自动识别新版本并重新制作汉化副本）。
     如果提示"版本无法自动识别"，说明新版代码结构有变化，
     请把窗口里的提示信息截图，到仓库提 issue。

  Q3：想用回英文原版？
  A：双击「恢复原版.bat」，然后从开始菜单打开 Codex 即可。
     原版安装完全没有被改动。

  Q4：想彻底卸载汉化？
  A：双击「卸载汉化.bat」，按提示确认。会删除汉化副本并恢复原配置。

  Q5：需要管理员权限吗？
  A：只需要安装和卸载时（复制微软商店安装目录）。
     日常启动汉化版不需要管理员权限。

  Q6：会动我的模型/API 配置吗？
  A：不会。只写入 localeOverride = "zh-CN"，
     不碰 auth.json、API Key 和任何模型设置。

五、原理简述（给感兴趣的人）
  1. 真正显示界面的程序是 ChatGPT.exe（Codex.exe 只是外壳）。
  2. 网页中文被 Statsig 功能层 72216192 的 enable_i18n 开关控制，
     默认关闭，服务器不下发就无法开启。
  3. 本工具在 app.asar 中做两处等长原位修改，把开关强制改为开启，
     并让程序加载内置的 zh-CN 语言包。
  4. 因为微软商店版不能原地修改，工具会复制一份到
     %USERPROFILE%\.codex\zh-cn-patched\ 下再修改，原版保持不动。

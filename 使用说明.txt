==========================================
  Codex Desktop 一键汉化包（zh-CN）v1.4.1
==========================================

一、这是什么？
  把微软商店版 Codex Desktop 的界面完整变成中文：
  - 左侧会话、新聊天、项目、计划、插件、设置等网页主体文字
  - 顶部 文件/编辑/视图/帮助 原生菜单
  安装过程全程离线，不需要登录 OpenAI 账号，API Key 模式同样生效。

二、两种使用方式
  方式 A（推荐，一句话）：在 Codex 里打开本仓库目录，对它说：
    「按本仓库 README 和 AGENTS.md 的说明，帮我把 Codex Desktop 界面汉化成中文」
  Codex 会自动运行安装脚本完成汉化（过程中弹出 UAC 请点「是」）。

  方式 B（兜底，双击）：直接双击「安装汉化.bat」，UAC 弹窗点「是」，
  在菜单中选择 1 安装汉化，完成后自动启动汉化版。

三、更新策略
  - Codex 自动更新后汉化失效：重新双击「安装汉化.bat」选 1 即可（会自动重建）。
  - 可选在线更新（默认关闭）：双击「检查更新.bat」，有新版本会自动下载并重新安装。
  - 提示"版本无法自动识别"：把 %USERPROFILE%\.codex\zh-cn-agent\logs\ 下的
    diagnostic-*.txt 文件内容提交到仓库 issue，维护者更新后会支持新版本。
  - 新版本通常能自动安装（通用探测）；安装成功时会自动导出候选特征串
    logs\candidate-<版本>.json，提交 issue 即可让维护者快速收录该版本。

四、常见问题
  Q1：打开后还是英文？
  A：安装后从任何入口打开 Codex，都会在约 1~2 秒内自动切换为中文版
     （原版英文窗口会短暂出现后被自动替换，属正常现象）。
     若未生效，先彻底关闭 Codex（任务栏右键退出），
     再重新双击「安装汉化.bat」选择 1 重新安装一次。

  Q2：Codex 自动更新了新版，汉化失效？
  A：重新双击「安装汉化.bat」选择 1 即可；若提示"版本无法自动识别"，
     按上方更新策略提交诊断文件。

  Q3：想用回英文原版？
  A：双击「恢复原版.bat」，然后从开始菜单打开 Codex 即可。
     原版安装完全没有被改动。

  Q4：想彻底卸载汉化？
  A：双击「卸载汉化.bat」，按提示确认。会删除汉化副本、恢复原配置并移除工具目录。

  Q5：需要管理员权限吗？
  A：只需要安装和卸载时（复制微软商店安装目录）。
     日常启动汉化版不需要管理员权限。

  Q6：会动我的模型/API 配置吗？
  A：不会。只写入 localeOverride = "zh-CN"，
     不碰 auth.json、API Key 和任何模型设置。

  Q7：会不会越用越臃肿？
  A：汉化副本只是程序本体的可写拷贝（约 1.7GB）；聊天记录存在共享的
     %USERPROFILE%\.codex\ 下，不会写进副本。Codex 更新后旧版本副本
     会在安装/卸载时自动清理，磁盘占用不会持续膨胀。

  Q8：会有常驻后台吗？
  A：安装后会有一个登录自启的轻量「入口自动切换助手」，仅在检测到
     原版入口被打开时动作，不联网、不自动打开 Codex、不读取账号数据；
     恢复原版/卸载时会自动移除。

  Q9：桌面快捷方式叫什么？
  A：中文系统为「Codex 汉化版」，其他语言系统为 ASCII 名「Codex zh-CN」；
     双击它可直接启动中文版。

  Q10：第一次安装为什么有点慢？
  A：需要把约 1.7GB 的程序复制一份并打补丁，杀毒软件扫描还可能
     造成几十秒延迟，1~3 分钟属正常，请耐心等待不要中断。

  Q11：每几分钟闪出一个命令行窗口正常吗？
  A：v1.3.5 及更早版本中，这是入口助手每 5 分钟自愈触发造成的
     短暂闪现，属正常现象，不影响使用；v1.3.6 起已改为完全隐藏
     启动，不再闪现。

  Q12：Codex 是 26.900+ 版本，汉化后界面仍是英文/装完打不开？
  A：26.900+（含 26.901.x）受官方完整性保护，app.asar 不允许改动
     （改动会在数秒后主动退出）。v1.3.9 起检测到这类版本会自动改用
     locale-only 模式：只写 localeOverride="zh-CN"，不再复制/补丁/
     装守卫。界面中文由官方 i18n 提供（联网/服务端开启后生效），
     这是此类新版本唯一可行的汉化方式。

  Q13：怎么防止 Codex 自动更新把汉化弄失效？
  A：安装菜单第 7 项或运行 -Action freeze 可关闭 Microsoft Store
     自动更新（策略 AutoDownload=2，需管理员）；也可在 Microsoft
     Store → 设置里关闭「自动更新应用」。恢复用菜单第 8 项或
     -Action unfreeze。这只对已装老版本（≤26.831）保住汉化有意义。

五、工具目录与日志
  - 固定工具目录：%USERPROFILE%\.codex\zh-cn-agent\（桌面快捷方式指向这里，
    仓库文件夹删除后汉化入口仍可用）
  - 汉化副本：%USERPROFILE%\.codex\zh-cn-patched\
  - 安装日志：%USERPROFILE%\.codex\zh-cn-agent\logs\
    （install-*.log 安装日志、launch-*.log 启动日志、entry-guard.log 入口助手日志；
      启动结果为 launch-result.json）

六、原理简述（给感兴趣的人）
  1. 真正显示界面的程序是 ChatGPT.exe（Codex.exe 只是外壳）。
  2. 网页中文被 Statsig 功能层 72216192 的 enable_i18n 开关控制，
     默认关闭，服务器不下发就无法开启。
  3. 本工具在 app.asar 中做两处等长原位修改，把开关强制改为开启，
     并让程序加载内置的 zh-CN 语言包。
  4. 因为微软商店版不能原地修改，工具会复制一份到
     %USERPROFILE%\.codex\zh-cn-patched\ 下再修改，原版保持不动。
  5. 特征串维护在 versions.json，未知版本走通用探测，仍失败则生成诊断文件。
  6. 安装完成后的重启由监督脚本完成：关闭旧进程 → 普通权限启动汉化副本 →
     验证稳定后立即退出（无后台驻留），全过程写日志与 launch-result.json。
  7. 为让“从任何入口打开都是中文”，另装一个登录自启的入口助手：事件驱动
     监听 codex/chatgpt 进程，发现原版被打开时自动关闭并拉起汉化副本；
     不联网，恢复原版/卸载时移除。
